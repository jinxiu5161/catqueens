## 1) 已定规则与建议实现约定

### 1.1 【产品已定】必须遵守

**产品与范围**
- 猫咪主题单机逻辑解谜；主线 500 关；核心循环：读关 → 放猫/标× → 规则反馈 → 通关 → 解锁内容。
- **无**每日挑战、签到、连续登录奖励、补签、日榜；**无**心/体力等待；**无**金币；**无**云存档/自建服务器（除非后续产品另批）。
- 客户端不运行关卡生成器；关卡离线内置 JSON。

**核心规则（PuzzleCore 唯一判定源）**
1. 每行恰好 1 只猫  
2. 每列恰好 1 只猫  
3. 每个四邻接连通色区恰好 1 只猫（区域数 = N）  
4. 任意两猫不可八方向相邻  

- 通关：恰好 N 只猫且全局满足全部规则；`isSolved` 为唯一通关依据（不能只用 `catCount === N`）。
- `EXCLUDED`（×）是玩家笔记，**不参与**合法性/唯一解/通关判定。
- `CONFLICT` 为运行时派生，**不得**写入存档或永久格子状态。
- 冲突猫不计入有效进度（`validCatCount`）。

**模式**
- 默认软引导：允许错误落子并展示冲突；玩家自行修正；不判负。
- 精英严判：拒绝本次落子并回滚；失败记录仅统计；**不**自动永久写 ×；无限重试；可切软模式；广告重试可选且非门槛。

**交互（首发默认方案）**
- 单击：EMPTY ↔ EXCLUDED；CAT 上单击无效/轻提示。
- 双击：放猫 / 撤猫（撤后回 EMPTY，不自动加 ×）。
- 滑动：沿途 EMPTY → EXCLUDED；不改 CAT。
- 长按：高亮行/列/色区，不改棋盘。
- 撤销：显式按钮，当前关至少 50 步。

**提示**
- 三级：必放格 → 逻辑关系 → 下一步推理结果。
- 必须基于**当前棋盘**（含玩家手动 ×）重新求解；禁止把 `solution` 下一格伪装成必然提示。
- 多解时不得声称某格必然；死局返回无解/建议撤销。
- 展示不改棋盘；确认应用后才成命令；无可用结果不扣券。

**经济（仅提示券）**
- 初始 2；上限 9；每 10 关首次通关 +1；成就合计约 20–30（配置表）；激励广告最多 2 次/自然日、每次 +1；溢出进 `pendingTicketRewards`。
- 每 50 关节点：猫/皮肤/章节纪念，**不**再叠加提示券。
- 不设每日登录券、月卡每日送券、每日任务。

**平台**
- 广告/IAP/榜单通过适配层；SDK 失败不得阻断离线主线。
- 插屏最多 3 次/自然日；提示券激励 2 次/自然日；无开屏/强制前贴片。
- 无可靠反作弊时，全球竞速榜可延期；首发可个人纪录 + 平台成就。

### 1.2 【建议实现】可评审调整的技术约定

| 主题 | 建议约定 |
|---|---|
| 索引 | 行/列/区域从 0 起；`index = row * size + col` |
| 格子状态 | `'EMPTY' \| 'EXCLUDED' \| 'CAT'`；冲突仅派生 |
| `LevelDefinition` | `id, size, regions[], solution?, chapterId?, difficulty?, elite?` |
| 冲突码 | `ROW \| COLUMN \| REGION \| ADJACENT_8` + `messageKey`（i18n） |
| 手势阈值 | 单击 ≤220ms/≤10pt；双击窗 260–320ms；滑动 ≥16pt；长按 450–500ms |
| 双击防闪变 | 首次点击待确认，双击窗结束前不提交单击 |
| 命令式撤销 | `BoardCommand`；滑动批量 = 1 条；新操作清空重做栈 |
| 求解器 | 回溯 + MRV；统计解数到 2 即停；超时 ≠ 唯一解 |
| 存档 | `SaveDataV1` + `schemaVersion`；原子写；无 hearts/daily/streak |
| 工程分层 | PuzzleCore 纯 TS、零 `cc` 依赖；UI 只消费逻辑结果 |
| 平台开发期 | `MockAdapter` 先跑通；真 SDK 后接 |
| 语言 | zh-CN / zh-TW / en / ja / ko；文案 key-value |
| 棋盘尺寸 | 设计覆盖至 11×11；小屏触控不过关可首发限 10×10 |
| levels 正式 JSON | 见规格 §4；若现有数据格式不同，先写导入适配器，不手工重录 |

### 1.3 红线（附录 B）

1. PuzzleCore 是唯一规则判定源。  
2. 行/列/区各一猫 + 八邻不相邻。  
3. × 非规则；冲突不可持久化。  
4. 严判只回滚，不永久排除。  
5. 提示基于当前局面；禁止伪装参考解。  
6. 客户端不生成关卡；500 关发布前独立 QA。  
7. 无每日/签到/连登/补签/日榜/心/体力/金币。  
8. 离线可玩；平台 SDK 失败不阻断主线。

### 3.3 关卡 JSON 目标格式（导入后）

```json
{
  "schemaVersion": 1,
  "levels": [
    {
      "id": 1,
      "size": 4,
      "regions": [0,0,1,1, 0,2,2,1, 3,2,2,1, 3,3,3,1],
      "solution": [0, 5, 10, 15],
      "chapterId": 1,
      "difficulty": 12,
      "elite": false
    }
  ]
}
```

加载校验：`regions.length === size²`；区域数 = size；四邻接连通；`solution` 若存在须合法；失败显式错误码，禁止静默换关。
