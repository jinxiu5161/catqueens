# 15.4 棋盘与输入 — 完成说明

## 交付内容

| 要求 | 实现 |
|---|---|
| BoardView | `assets/scripts/ui/board/BoardView.ts` — 色区/边界/猫/× 渲染 |
| BoardInputController | `assets/scripts/core/input/BoardInputController.ts` |
| 单击排除图标 | `applyTap`；与猫同级的圆形 × 图标（`CellIcons.drawExcludeIcon`） |
| 双击放猫/撤猫 | `applyDoubleTap`；在排除格上双击会去掉排除并放猫 |
| 滑动批量排除 | `applySwipeExclude`；滑过猫格不标排除 |
| 放猫后笔记引导 | 同行/同列/八邻 EMPTY 格浅色提示（不自动写入排除） |
| 长按高亮行/列/色区 | `BoardView.setHighlight`；松手清除 |
| 双击窗不闪变 | `GestureRecognizer` 首次点击 pending，超时才提交单击 |
| 软引导冲突展示 | 允许落子；`ConflictPresenter` 只消费 PuzzleCore 冲突 |
| 严判回滚 | `mode==='strict'` 时拒绝非法落子，不写命令栈 |
| UI 不复制规则 | 判定只走 `puzzleValidator` |

## 测试

```bash
npx vitest run tests/input
```
